步驟 1你說一句話

範例：下面的對話是示範，不是實際的聊天紀錄。Designer 用日常的話提出要求。

  1. Designer

    把標題放大，深色模式也要好讀

  2. AI

    我先讀了 docs/design.md 的規則，再改了 styles/main.css 和 tokens/tokens.json：標題字級放大，深色模式的文字色改用對應的 token。改完執行了 wda build，建置通過。

步驟 2AI 改的是專案檔案

這個頁面的 source 就是下面這棵專案樹。設計規則、token 和頁面都是檔案，不留在聊天紀錄裡。wda.json、README.md 和 docs/ 不會進入 dist/。

  • wda.json專案契約的核心：專案識別、技術基準與使用的 Design System
  • README.md專案說明
  • docs/專案文件：architecture.md、design.md、naming.md
  • pages/頁面進入點，pages/index.html 建置為 dist/index.html
  • styles/共用的 source 樣式表，直接對應到 dist/styles/
  • scripts/TypeScript 互動模組，先型別檢查，再轉譯為 dist/scripts/ 的 JavaScript
  • tokens/tokens.json，建置時轉譯為 dist/styles/tokens.css
  • assets/專案自備的圖片、字型與圖示，只複製頁面實際參照的檔案
  • deno.jsonc唯一的專案相依宣告檔
  • deno.lock鎖定檔，與 deno.jsonc 共同管理外部相依

步驟 3wda build 印出的全部內容

這是在這個專案資料夾執行 wda build 的完整輸出，沒有刪減。

WDA 一共只有四個指令：wda init 建立新專案與本機 Git 儲存庫，wda deps 管理 dependency graph，wda check 只驗證、不產出，wda build 驗證通過後建置輸出 dist/。

$ wda build
Build succeeded.
Output: <project>/dist
HTTP server required; opening via file:// will not work.

結束碼 0。實際輸出的是本機的絕對路徑，這裡已正規化為 <project>/dist。執行檔由這個儲存庫建置，擷取日期 2026-10-13。

步驟 4你帶走 dist/

dist/ 是唯一的部署產物，沒有 WDA 也能獨立運作。scripts/main.js 打包了 Spectrum 元件，是其中最大的檔案。

大小取自最終執行 wda build 產生的 dist/，以 KiB 四捨五入到整數，量測日期 2026-10-13。

安裝 WDA

先在 PATH 中備好 Git 與 Deno。WDA 不需要 Node.js。選一條路徑安裝，目前穩定版是 v0.1.0。

Homebrew
brew install monkey1wizard/tap/wda
WinGet
winget install Monkey1Wizard.WDA
Cargo
cargo install --git https://github.com/monkey1wizard/Web-Design-Anchor --tag v0.1.0 wda --locked
Releases

到 GitHub Releases 下載符合平台的資產，再用安裝程式：Linux 與 macOS 用 packaging/install.sh，Windows 用 packaging/install.ps1。安裝程式會驗證 SHA-256 checksum。

檢查
wda --version

你帶走的是純靜態、零依賴的 dist/，歸你保管。
