我不會寫程式，也能用嗎？

可以。即使你不是工程師、不熟悉網頁開發，搭配 WDA 和 AI 聊天，就能做出簡單、好維護的靜態網頁。產出的網頁專案架構清楚，頁面、樣式和設計規範都有固定的位置。因此不只是內容好改，配色、字級等設計風格也能集中調整，網站改版多次也不會走樣。

  2. AI，範例

專案裡有什麼？

專案資料夾裡是你和 AI 維護網站用的檔案：頁面、樣式、Design Tokens、程式與專案文件。

設計靠文件維護。docs/design.md 記錄這個專案的設計規則：採用的 Design System、無障礙基準、視覺審查標準與設計方向。AI 依照這份文件判斷畫面是否合格，改完後再把需要持續適用的決定寫回文件，所以設計規則會留在檔案裡，不會散落在聊天紀錄中。

  • website/
    • pages/頁面進入點
    • styles/樣式表
    • tokens/Design Tokens：顏色、字級、間距等設計數值
    • scripts/TypeScript 程式
    • docs/專案文件
      • design.md設計規則，AI 依這份判斷畫面
    • wda.json專案名稱、技術基準、Design System 與 WDA 版本
    • README.md專案說明
    • dist/由 wda build 建立，用來部署

wda build 建立了什麼？

wda build 是 WDA 的建置指令，由 AI 在改完檔案後執行。它會先檢查專案，發現錯誤就停止，不會更動 dist/。檢查通過後，才會建立 dist/。

dist/ 只用來部署。每次執行 "wda build" 後都會重新產生整個 dist/，所以不要手動修改它。

  • dist/
    • index.html19 KiB
    • styles/
      • main.css18 KiB
      • tokens.css2 KiB
    • scripts/
      • main.js408 KiB

不用 WDA 之後，網站還能跑嗎？

能。WDA 只在建立和建置專案時使用，網站執行時不需要它。dist/ 放到任何靜態主機都能運作。

$ wda buildBuild succeeded.Output: <project>/distHTTP server required; opening via file:// will not work.

怎麼開始？

先準備好 Git 與 Deno，不需要 Node.js，選一種方式安裝。

macOS 與 Linux

Homebrew
brew install monkey1wizard/tap/wda
終端機輸入
curl -fsSL https://raw.githubusercontent.com/monkey1wizard/web-design-anchor/main/packaging/install.sh | bash

Windows

WinGet
winget install Monkey1Wizard.WDA
PowerShell輸入
irm https://raw.githubusercontent.com/monkey1wizard/web-design-anchor/main/packaging/install.ps1 | iex

已安裝 Rust

Cargo
cargo install --git https://github.com/monkey1wizard/Web-Design-Anchor --locked

安裝之後

確認版本
wda --version
建立新專案
wda init

建立新專案時，在空的目標資料夾執行 wda init，即可產生標準專案目錄結構與設定檔，並交由 AI 協助開發。

兩個「安裝程式」會從 GitHub Releases 下載最新穩定版並驗證 SHA-256。也可以到 GitHub Releases 手動下載。
