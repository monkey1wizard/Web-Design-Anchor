Web Design Anchor

Build websites with AI. Keep design decisions in your project.

Can I use it without coding?

Yes, if you use an AI coding tool that can run commands on your computer, such as Claude Code or Codex. Git is optional. WDA Minimal needs no Deno, Node.js, or Bun. You don't need to write the code yourself.

The project keeps pages, styles, and design rules in clear locations. You can edit content and adjust colors, type, and other design choices in one place.

  1. Designer, example

    Make the heading larger and keep it readable in dark mode.

  2. AI, example

    I read docs/design.md, updated styles/main.css and tokens/tokens.json, then ran wda build successfully.

What is in the project?

The project folder contains the files you and your AI coding tool use to maintain the site: pages, styles, design tokens, code, and project documentation.

Design is maintained through documentation. docs/design.md records the project's design system, accessibility baseline, visual review criteria, and direction. The AI can use it to assess the page and write lasting decisions back to the file, so design rules stay with the project instead of getting lost in chat history. You still review the page yourself.

What does wda build create?

The AI usually runs the WDA build command after it updates files. You can also run it yourself. The command checks the project first and stops on errors without changing dist/. It creates dist/ only after the checks pass.

dist/ is for deployment. Each run of wda build recreates the entire folder, so do not edit it by hand.

Will the site still work without WDA?

Yes. WDA is used to create and build the project, but the site does not need it to run. The files in dist/ work on any static host.

$ wda buildBuild succeeded.Output: <project>/distHTTP server required; opening via file:// will not work.

How do I get started?

Git is optional. WDA Minimal needs no Deno, Node.js, or Bun. The default Spectrum and Lit packages use an existing package manager, npm or Bun. Then choose an installation method.

macOS and Linux

Homebrew
brew install monkey1wizard/tap/wda
Run in a terminal
curl -fsSL https://raw.githubusercontent.com/monkey1wizard/web-design-anchor/main/packaging/install.sh | bash

Windows

Run in PowerShell
irm https://raw.githubusercontent.com/monkey1wizard/web-design-anchor/main/packaging/install.ps1 | iex
WinGet In progress
winget install Monkey1Wizard.WDA

If Rust is installed

Cargo
cargo install --git https://github.com/monkey1wizard/Web-Design-Anchor --locked

After installation

Check the version
wda --version
Create a project
wda init

To start a new project, run wda init in an empty target folder. It creates the standard project structure and configuration for you to develop with an AI coding tool.

The two installers download the latest stable release from GitHub Releases and verify its SHA-256 checksum. You can also download a release manually.
