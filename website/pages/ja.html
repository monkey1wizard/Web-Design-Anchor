Web Design Anchor

AIでウェブサイトを作り、デザインの決定はプロジェクトに残す。

  1. コードを書けなくても使えますか？
  2. プロジェクトには何がありますか？
  3. wda build で何が作られますか？
  4. WDA がなくてもサイトは動きますか？
  5. 始めるには？

コードを書けなくても使えますか？

はい。Claude CodeやCodexなど、パソコン上でコマンドを実行できるAIコーディングツールを使っていれば使えます。Gitは任意です。WDA MinimalにはDeno、Node.js、Bunは不要です。コードを自分で書く必要はありません。

生成されるプロジェクトでは、ページ、スタイル、デザイン規則の置き場所が整理されています。コンテンツだけでなく、色や文字のスタイルも一か所で調整できます。

  1. Designer（例）

    見出しを大きくして、ダークモードでも読みやすくしてください。

  2. AI（例）

    docs/design.md を確認し、styles/main.css と tokens/tokens.json を更新してから wda build を実行しました。ビルドに成功しました。

プロジェクトには何がありますか？

プロジェクトフォルダーには、あなたとAIコーディングツールがサイトを保守するためのファイルが入っています。ページ、スタイル、デザイントークン、コード、プロジェクト文書です。

デザインは文書で管理します。docs/design.md には、デザインシステム、アクセシビリティ基準、ビジュアルレビュー基準、デザイン方針を記録します。AIはこの文書をもとに画面を確認し、継続して適用する決定をファイルに書き戻せます。デザイン規則がチャット履歴に埋もれず、プロジェクトに残ります。最終的な画面はご自身で確認してください。

  • website/
    • pages/ページの入口
      • index.html
      • zh-TW.html
      • ja.html
    • styles/スタイルシート
    • tokens/デザイントークン：色、文字サイズ、余白などのデザイン値
    • scripts/TypeScript コード
    • docs/プロジェクト文書
      • design.mdAIが画面を判断するためのデザイン規則
    • anchor.jsonプロジェクト名、技術基準、デザインシステム、WDAのバージョン
    • package.jsonビルドが使う npm パッケージ
    • README.mdプロジェクトの概要
    • dist/wda build が作成するデプロイ用ファイル

wda build で何が作られますか？

WDAのビルドコマンドは、通常AIがファイルを更新した後に実行します。自分で実行することもできます。最初にプロジェクトを検査し、エラーがあれば停止して dist/ は変更しません。検査に合格した後で dist/ を作成します。

dist/ はデプロイ用です。wda build を実行するたびにフォルダー全体が作り直されるため、手動で編集しないでください。

WDA がなくてもサイトは動きますか？

はい。WDAはプロジェクトの作成とビルドに使いますが、サイトの実行には必要ありません。dist/ のファイルはどの静的ホストでも動作します。

$ wda buildBuild succeeded.Output: <project>/distHTTP server required; opening via file:// will not work.

始めるには？

Gitは任意です。WDA MinimalにはDeno、Node.js、Bunは不要です。既定のSpectrumとLitのパッケージは、既存のパッケージマネージャーであるnpmまたはBunを使います。次にインストール方法を選びます。

macOS と Linux

Homebrew
brew install monkey1wizard/tap/wda
ターミナルで実行
curl -fsSL https://raw.githubusercontent.com/monkey1wizard/web-design-anchor/main/packaging/install.sh | bash

Windows

PowerShell で実行
irm https://raw.githubusercontent.com/monkey1wizard/web-design-anchor/main/packaging/install.ps1 | iex
WinGet 準備中
winget install Monkey1Wizard.WDA

Rust をインストール済みの場合

Cargo
cargo install --git https://github.com/monkey1wizard/Web-Design-Anchor --locked

インストール後

バージョンを確認
wda --version
新しいプロジェクトを作成
wda init

新しいプロジェクトを始めるには、空のフォルダーで wda init を実行します。標準のプロジェクト構成と設定ファイルが作成され、AIコーディングツールと開発を始められます。

2つのインストーラーは GitHub Releases から最新の安定版をダウンロードし、SHA-256 を検証します。リリースを手動でダウンロードすることもできます。
